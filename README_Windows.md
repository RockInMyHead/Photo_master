# Photo Master - Windows Setup Guide

## 🚀 Быстрый запуск

### Первый запуск (с установкой зависимостей):
```cmd
start.bat
```

### Повторные запуски (если зависимости уже установлены):
```cmd
run.bat
```

## 📋 Что делают batch файлы

### `start.bat` - Полная установка и запуск
1. ✅ Проверяет наличие Python и Node.js
2. 📦 Создает виртуальное окружение Python
3. 📦 Устанавливает зависимости backend (pip install)
4. 📦 Устанавливает зависимости frontend (npm install)
5. 🚀 Запускает backend сервер (порт 8000)
6. 🚀 Запускает frontend сервер (порт 5173)

### `run.bat` - Быстрый запуск
1. ✅ Проверяет наличие виртуального окружения и node_modules
2. 🚀 Запускает backend сервер
3. 🚀 Запускает frontend сервер

## 🔧 Ручной запуск (если нужны отдельные окна)

### Backend:
```cmd
cd backend
venv\Scripts\activate.bat
python -m uvicorn app:app --reload --host 0.0.0.0 --port 8000
```

### Frontend:
```cmd
cd frontend
npm run dev
```

## 📱 Доступ к приложению

- **Веб-интерфейс**: http://localhost:5173
- **API Backend**: http://localhost:8000

## 🛠️ Системные требования

- **Python 3.9+** (автоматически проверяется)
- **Node.js 18+** (автоматически проверяется)
- **Windows 10/11**

## 🔧 Устранение неполадок

### Если batch файл не запускается:
1. Убедитесь что файл имеет расширение `.bat`
2. Запустите командную строку как администратор
3. Проверьте что Python и Node.js установлены

### Если сервера не запускаются:
1. Убедитесь что порты 8000 и 5173 свободны
2. Проверьте что виртуальное окружение создано (`backend\venv\`)
3. Проверьте что зависимости установлены (`frontend\node_modules\`)

### Очистка и переустановка:
```cmd
# Удалить виртуальное окружение
rmdir /s backend\venv

# Удалить node_modules
rmdir /s frontend\node_modules

# Перезапустить установку
start.bat
```

## 📞 Поддержка

Если возникли проблемы:
1. Проверьте логи в окнах серверов
2. Убедитесь что все зависимости установлены
3. Проверьте что порты не заняты другими приложениями
